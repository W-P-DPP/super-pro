# Validation

仅当准备结束实现、回归验证、补充测试说明或做前端评审时读取本文件。

## 最低验证要求

- 结果符合 `design.md`
- 结果符合目标项目主题源
- UI、类型、样式、API 能力已优先复用共享包
- 关键页面在移动端可读、可点、无明显横向溢出
- 已运行目标前端项目构建

## 按改动范围补充验证

- 仅前端项目页面或组件改动：运行目标前端项目构建
- 涉及共享 UI：补运行 `<shared-ui>` 的构建或测试
- 涉及共享类型或 DTO：补运行 `<shared-types>` 的构建或测试
- 涉及共享样式或主题 token：补运行 `<shared-styles>` 的构建或目标前端构建
- 涉及 API 模板、鉴权、跳转工具：补运行 `<shared-web>` 的测试或相关构建

## 体验检查

- 浅色与深色主题都检查
- 弹窗、抽屉、菜单、选择器在桌面端和移动端都能正常打开和关闭
- 主操作在窄屏下可达
- 表格、图表、筛选区在窄屏下有明确降级方案

## 输出要求

最终回复至少说明：

- 实际运行了哪些命令
- 哪些检查是人工确认的
- 哪些项未验证
- 未验证项的原因和风险
